# 2020 College Prototype Archive

This directory contains the original 2020 academic prototype and associated
material from this repository. It is retained for historical traceability only.

It is not part of the modern CardioSentinel pipeline, has not been validated for
clinical use, and must not be modified as part of normal development. Its
fixed-threshold outputs must not be interpreted as medical diagnoses.

The archived sample CSVs have only a `hart` column and lack verified source,
patient, lead, unit, sampling, annotation, and licensing metadata. They are not
approved CardioSentinel data and must not be used for experiments. The screenshots
in `Results/` are historical manual captures, not reproducible experimental
evidence.
